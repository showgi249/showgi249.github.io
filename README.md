# SHOWGI249 — مركز الهوية الرقمية

موقع شخصي لأحمد شوقي (SHOWGI249)، يعرض المنشورات من يوتيوب و Telegram تلقائياً.

## 🏗️ البنية

- **Frontend**: HTML + CSS + JavaScript (بدون إطار عمل).
- **Data**: ملف `content.json` يُحدَّث تلقائياً عبر GitHub Actions.
- **Backend Script**: Python 3.12 (`sync_content.py`).
